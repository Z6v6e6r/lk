# Родина · Viva 005JDA · Tilda T123

Копия публичного сайта https://cg178013.tw1.ru/, сохранённого 10 ноября 2026 года. Оформление, фотографии, тексты, поиск манежей, мобильная и настольная версии взяты из исходного сайта. Все девять услуг аренды заново сверены с Viva tenant `005JDA`: заменены ID услуги, подуслуги, локации и зала. Список привязок — `audit/catalog.json`; старый tenant не используется в runtime.

Кнопка после выбора времени автоматически получает цену всего выбранного интервала и показывает «Перейти к оплате · … ₽». Во время расчёта она заблокирована. Новая дата/длительность/слот сбрасывают предыдущую цену. Повторный расчёт после ошибки только показывает сумму; если цена изменилась перед переходом, требуется ещё одно явное нажатие.

## Небольшие блоки для Тильды

Предыдущие большие сниппеты заменены комплектом из **19 блоков T123**. Каждый файл занимает менее 17 КБ. Код, шрифты, разметка и стили содержатся внутри комплекта в сжатом виде; отдельный сервер для JavaScript не нужен. Последний блок собирает части, проверяет SHA256 и запускает приложение один раз. Фото и правовые PDF загружаются по прежним рабочим URL.

1. На пустой странице добавьте 19 блоков T123 без внешних отступов. Отключите общие шапку и подвал: копия уже содержит свои.
2. Откройте текстовым редактором файлы из `ДЛЯ_КОПИРОВАНИЯ` и вставьте каждый **целиком в свой T123**, по порядку 01 → 19. В папке `tilda` находятся те же исходники как HTML.
3. Файл `START` должен быть последним. Уберите предыдущий большой комплект. Не смешивайте части разных сборок. Порядок перечислен в `ORDER.txt`.
4. Проверьте опубликованную HTTPS-страницу. Нужен современный браузер с `DecompressionStream`: актуальные Chrome/Яндекс/Edge, Safari 16.4 и новее. При недостающей или повторяющейся части показывается ошибка; неполный код не запускается.
5. Для VK/Яндекс входа реальный HTTPS URL страницы должен быть разрешён в Viva/Keycloak как redirect URI. Реальный вход, отправка SMS, создание брони и платежи при подготовке не выполнялись.

`site/index.html` — отдельный готовый сайт; `site/compact-preview.html` — локальная проверка сборки из тех же маленьких частей с соседними медиа. `source/` — исходники. `CHECKS.json` и `CATALOG.json` — проверки и карта всех девяти услуг.

## Пересборка

Нужен Node.js 22+ и npm. Единственная зависимость сборки — esbuild 0.27.2; серверные ключи и runtime-зависимости не нужны.

```sh
cd source
npm ci
npm test
npm run build
npm run preview
```

Медиа уже включены в архив передачи. В Git хранятся их публичные URL и SHA256: при сборке недостающие файлы скачиваются с исходного сайта и проверяются. Для текущего локального SOCKS при необходимости задайте `RODINA_DOWNLOAD_PROXY=socks5h://127.0.0.1:17892`. Файлы с несовпавшим хешем не принимаются.

После сборки файлы находятся в `dist/`, небольшие блоки — в `dist/tilda/`. Для повторной конвертации фото установите системный `cwebp` (например, пакет `webp` в Homebrew) и выполните `npm run images:webp`. Это необязательный инструмент подготовки изображений, без runtime-зависимостей. Просмотр — http://127.0.0.1:4375/ . Для реальной загрузки Viva используйте доступный сетевой маршрут; проверка через другой VPN-маршрут может давать сетевую ошибку.

```sh
RODINA_ASSET_BASE=https://your-owned-host.example/rodina npm run build
```

Переменная меняет базу только фотографий и PDF, не tenant и не адреса Viva. Самостоятельный `dist/index.html` использует соседние локальные `assets/` и `docs/`. Передайте весь каталог `dist` при самостоятельном размещении.

## Сверка услуг

`src/arenas.json` содержит точные привязки девяти манежей. Код проверяет весь комплект tenant/service/subservice/studio/room до сетевого запроса. Отчёт сохраняет реальные названия Viva, включая «Севастопальская» и «Хорошевская»; названия на сайте сохранены из оригинала.

`audit/widgets.json` содержит ID публичных виджетов. `scripts/sync-public-catalog.py` заново читает их настройки и публичные meta/subServices/studios, останавливается при неоднозначности. `scripts/check-public-booking.mjs` проверяет только публичные meta, timeslots, validate и price. Оба скрипта используют SOCKS `127.0.0.1:17892` этой рабочей машины; для другой среды адаптируйте маршрут. Они не запрашивают вход и не вызывают оплату/бронь.

## Проверено и оставшиеся границы

Проверены локальные тесты изоляции tenant/OAuth, смешанных ID, потери ответа оплаты, изменения цены и гонок расчёта; сборка и scoped ESLint. Публичные расписания всех девяти услуг ответили успешно. Для свободных интервалов 11 ноября Viva вернула цены; пустой список остальных площадок не считается ошибкой.

В браузере проверяются локальные сборки; отдельный read-only релей использован для живого чтения Viva через SOCKS и не входит в опубликованный код. Релей не допускает авторизацию/создание брони/оплату. Фактическая публикация в Тильде, разрешение OAuth для нового адреса, вход и платежи остаются отдельной приёмкой. Исходный сайт, Viva и production не изменялись.
