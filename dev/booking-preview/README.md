# Локальный стенд интерфейсов записи

Запуск из корня этого worktree:

```sh
npm exec -- vite --config dev/booking-preview/vite.config.ts
```

Адрес: http://127.0.0.1:5173/. Сервер слушает только локальный компьютер.
Стенд использует существующие React-компоненты из `src/`: создание игры,
поиск открытых игр, приглашение в игру, расписание тренировок и деталей
тренировки, афишу турниров и карточку записи на турнир. Правки компонентов
сразу обновляют открытый экран через Vite HMR.

В меню доступны шесть основных сценариев и поиск игр. Переключатель ширины
задаёт реальную ширину iframe, поэтому работают мобильные media queries.
Состояния: есть места, нет мест, уже записан, гость, загрузка, пусто, ошибка.
«Нет мест» / «Уже записан» относятся к присоединению, а не к созданию игры.
В режиме гостя можно пройти тестовую форму входа с произвольным кодом.
«Сбросить» очищает изменения тестовой записи, перезагружая iframe.
Параметры `screen`, `state`, `width` сохраняются в URL.

Данные синтетические. API заменяются только отдельной конфигурацией стенда;
обычные dev/prod-сборки не используют эти замены. Запись меняет только память
страницы. Оплата имитируется успешным результатом без платёжной ссылки.
CSP разрешает сетевые запросы только к локальному серверу. Внешние переходы,
формы, popup-окна и навигация родительской страницы ограничены iframe.
Неизвестный метод API возвращает ошибку стенда и предупреждение в консоли.

Проверка типов и отдельная сборка стенда:

```sh
npm exec -- tsc --project dev/booking-preview/tsconfig.json --noEmit
npm exec -- vite build --config dev/booking-preview/vite.config.ts
```

Результат сборки: `dist/booking-preview/`. Для работы над интерфейсом используйте
сервер разработки, а не производственный IIFE bundle.

## Матрица способов записи

В панели «Ваши привилегии» доступны все восемь сочетаний Резидентства,
подписки и абонемента. Флажки применимости отдельно проверяют, подходит ли
тариф подписки/абонемент к событию. Дневной бесплатный лимит задаётся отдельно. Настройки сохраняются
в параметрах `privileges`, `subscriptionFits`, `passFits`.

Тестовые цены из предоставленной владельцем матрицы:

| Услуга | Полная цена | С Резидентством |
| --- | ---: | ---: |
| Корт целиком, за всех | 4 000 ₽ | Льготы не применяются |
| Моя доля ¼ в игре 2×2 | 1 000 ₽ | 700 ₽ (−30%) |
| Групповая тренировка | 5 500 ₽ | 2 750 ₽ (−50%) |
| Турнир | 8 000 ₽ | 4 000 ₽ (−50%) |

Это примеры отображения, а не подтверждённые действующие тарифы. Подписка
может давать одну бесплатную тренировку в день либо один бесплатный час в
день. После использования дневного бесплатного лимита подписка остаётся
доступной со скидкой: игры — 30%, групповые и турниры — 50%. Подходящий
абонемент отдельно списывает одно посещение. Эти варианты не объединяются
с Резидентством. Если применимой
привилегии нет, доступна полная цена; иначе она показывается зачёркнутым
ориентиром. Доступные способы остаются независимыми и выбираются явно.

Неоформленные привилегии показываются как предложения с информационным
окном. Они не дают права записаться бесплатно и не активируются кликом.
Цена/условия оформления привилегий не выдуманы. Неприменимый продукт остаётся
видимым с пояснением, но не становится способом записи.

«Сравнить услуги» показывает три карточки одновременно. Новая панель также
встроена в детали игры, тренировки и турнира, в запись из списков и в
финальный шаг создания игры. `previewTransform.ts` меняет только checkout
JSX при компиляции отдельным конфигом стенда; исходники `src/` и обычные
сборки не меняются. При несовпадении ожидаемых областей JSX сборка стенда
останавливается, чтобы не показать старый и новый checkout одновременно.

Подтверждение/отмена в новой панели меняют только её локальное состояние.
Они не вызывают платёжные API, не списывают реальные посещения, не меняют
состав в других компонентах и сбрасываются при перезагрузке/смене профиля.

Проверки матрицы и областей подстановки:

```sh
node --experimental-strip-types --test dev/booking-preview/paymentMatrix.test.ts dev/booking-preview/gamePaymentOptions.test.ts dev/booking-preview/gameSubscriptionComparison.test.ts dev/booking-preview/previewTransform.test.ts
npm exec -- eslint dev/booking-preview
```

Владелец сценариев — PadlHub; аудитория — локальная работа над интерфейсом.
Критерий результата — восемь сочетаний привилегий для трёх услуг, независимый
выбор способа, состояния недоступности и корректный мобильный вид.
Сигнал остановки — смешанный checkout или запрос к внешнему сервису.
Остановить стенд можно через Ctrl+C в терминале Vite; внешних операций
для отмены у прототипа нет.

## Дневной лимит и исключённые групповые

В панели стенда отдельно переключаются:

- тариф: `subscriptionPlan=daily-training` (бесплатна только одна тренировка)
  или `daily-hour` (один бесплатный час);
- дневной бесплатный лимит: `dailyQuota=available` / `used`;
- категория групповых: `groupCategory=standard` / `excluded`.

Неприменимость тарифа, уже использованный бесплатный лимит и исключённая
категория — три разные причины. Использованный лимит не отключает подписку:
она предлагает самостоятельную запись за 700 ₽ (¼ корта) / 2 750 ₽ / 4 000 ₽ в примерах
стенда. До использования дневной тренировки этот тариф не делает игру или
турнир бесплатными. При неприменимом тарифе скидка не предлагается.

Для исключённой категории групповых отключены и бесплатная запись по
подписке, и её платная скидка, и цена по Резидентству. По подходящему
абонементу по-прежнему можно записаться; если он не подходит, остаётся полная
цена. В расписание добавлена отдельная тестовая «Групповая тренировка без
льгот», которая сохраняет исключение независимо от общего переключателя.

Если доступен бесплатный час, а событие длится 90 минут, показывается
60 минут бесплатно + 30 минут с доплатой. Пользователь подтвердил такую
частичную оплату, но формула доплаты ещё не определена. Стенд показывает
«Нужен расчёт» без выдуманной суммы, не разрешает подтверждение этого
варианта и сохраняет остальные доступные способы записи. При событии до
60 минут целиком используется бесплатный час. Длительность берётся из
события/выбора мастера создания игры, а не подменяется фиксированным часом.

Переключатель лимита — тестовое состояние: запись в одной карточке не
изменяет дневные лимиты в остальных карточках и не задаёт реальную политику
возврата лимита при отмене.

## Подписи предложений

Если подписки у пользователя нет, предложение называется «Бесплатно при
наличии подписки». Условия тарифа, дневного лимита, доплаты и исключённой
категории по-прежнему проверяются отдельно: подпись не даёт права на
бесплатную запись. Для исключённых групповых сохраняется нейтральное
«Подписка» с причиной недоступности.

Если событие доступно по пакету, показываем «По абонементу Энергия 5» и
19 800 ₽ как цену покупки всего пакета из пяти посещений. Для владельца
абонемента сохраняется списание одного посещения, без оплаты пакета заново.
Неприменимый абонемент не становится доступным от изменения подписи.

## Кто оплачивает игру

На шаге даты/времени после выбора корта возвращён выбор «Плачу за себя»
(¼ стоимости) / «Плачу за всех» (весь корт). Он использует состояние мастера,
поэтому выбранный плательщик сохраняется при переходе к подтверждению и
возврате через «Изменить».

Для «Плачу за всех» доступна только полная стоимость выбранного корта.
Подписка, Резидентство и абонемент не применяются ни как скидка, ни как
бесплатная запись. Полная цена не перечёркивается.

Для «Плачу за себя» базовая цена равна четверти стоимости выбранного корта.
Подходящая подписка с доступным бесплатным часом даёт 0 ₽ в пределах часа;
при превышении времени показываются бесплатные минуты и доплата без суммы,
пока не определена её формула. После использования дневного лимита подписка
даёт скидку 30% на личную долю. Резидентство отдельно даёт скидку 30% на
личную долю: её базовая цена зачёркнута рядом с льготной ценой. Применимость
тарифа по-прежнему независима от состояния дневного лимита.

Пример: корт 4 000 ₽ → личная доля 1 000 ₽ → со скидкой 30% — 700 ₽.
Цена покупки «Энергия 5» не делится на четверых. Ранее согласованный вариант
подходящего абонемента сохраняется только для личной записи.

Карточка присоединения и колонка игры в сравнении используют личную долю,
а не полную стоимость корта. Старая секция split-checkout скрыта только в
сборке стенда, чтобы не показывать противоречащие способы оплаты рядом.

Точность расчёта денег в прототипе — до копейки; реальное распределение
округлений, списание лимитов и платёжные операции не реализованы.

На этапе выбора личной ¼ цена «По подписке» показывает сравнение с подходящей
подпиской, даже если её нет или текущий тариф не подходит. До 60 минут — 0 ₽;
сверх часа — только платное время, пропорционально личной доле за выбранную
длительность, с округлением до копейки. Например, 1 000 ₽ за 90 минут →
333,33 ₽ за оставшиеся 30 минут. Это ориентир для сравнения; подтверждение
записи по-прежнему требует применимого продукта и отдельного расчёта доплаты.

На этапе выбора личной ¼ больше не выбирается одна «лучшая» цена для
показа. В карточке всегда три строки: базовая ¼ стоимости, по подписке,
с Резидентством. Тариф только для тренировок остаётся видимым с причиной;
предложения привилегий не дают права на запись.
Выбор конкретного способа оплаты остаётся на финальном шаге.
