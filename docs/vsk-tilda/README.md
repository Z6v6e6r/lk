Для нового направления сохраняется режим просмотра без онлайн-записи:
`6977:2349` добавлен в `bookingDisabledCategoryKeys` в `2-controller.html`.
Эта правка не открывает новый маршрут записи и не меняет условия подписки.

внести только эти две правки в соответствующие T123, сохранив остальные текущие

## Серверное правило

`scripts/patch_live_lk1_vsk_friendship.mjs` строит точечный кандидат из
fresh live flow 147, SHA256
`f3b860cadac4b0ea74acb5a112daa99adc151f03b83f5dc728634beb0567c78f`.

Копируется установленное правило обычной «Дружбы», меняется только productId:
60 бесплатных минут, максимум 8 активных записей с льготой,
30% на платную часть игры, 50% на доступные групповые тренировки и турниры.
После использования дневного визита или при 8 активных записях сохраняется
денежная скидка, без нового списания посещения. Дата когорты: с 01.09.2026.
Неизвестная дата покупки, неподтверждённое владение/срок/заморозка дают отказ.
Особые 90 минут и четверть корта Топократов ВСК не получает.

Изменяются только три поля двух узлов:

- `lk_subscription_booking_router_20260804`: `initialize`, `func`;
- `lk_subscription_price_preview_20260908_router`: `func`.

Все 11 прежних правил, evaluator, wires, HTTP inputs и платежные узлы сохранены.
Затронуты существующие `POST /lk/subscription-bookings` и
`POST /lk/subscriptions/game-price-preview`. Новых endpoints и tracked flow JSON нет.
Writer принимает точный prior, собственное итоговое значение или пустой контекст
после штатного restart; чужой prior не перезаписывает. Парный rollback проверяет
точный кандидат и возвращает исходные bytes. Он не отменяет реальные платежи/брони.

```sh
VSK_FRIENDSHIP_LIVE_FLOW=/absolute/private/source.flow.json node --test scripts/tests/vskFriendship.test.mjs
node scripts/patch_live_lk1_vsk_friendship.mjs /absolute/private/source.flow.json /absolute/new-private-output
```

При drift полного flow или любого из трёх полей требуется новый проверенный
rebase; не отключать hash guards. Перед разрешённым apply подтвердить fresh source,
pushed source/CI, lock/lease и backup по `docs/NODERED_MODULAR_WORKFLOW.md`.
Восстановление требует штатного restart с memory-only globals; при persistent
context нужен отдельный проверенный обратный transition. После apply проверить
runtime readback 12 правил, PM2 и quote. Наличие initializer на диске не является
доказательством in-memory state.

## Покупка и Tilda

`vsk` — фиксированный monthly-only offer существующего checkout.
Цена и activationDays читаются из точного Viva продукта и повторно проверяются
перед отправкой. UUID/срок/посещения/направления/типы проверяются до платежа.
Действуют существующие locks, durable pending, `retries: 0` и ручное подтверждение.
`vsk-year`, произвольные UUID, загрузка страницы и банковский возврат покупку не создают.

Заменить **содержимое**, сохранив сами T123 и все остальные блоки:

| Блок | Файл | Изменение |
| --- | --- | --- |
| `rec5171155001` | `1-settings.html` | Месячный `vsk`, цена/условия, точные категории ВСК и друзей, кабинет |
| `rec5171283401` | `2-controller.html` | Удаление кнопки «Год», покупка через LK checkout, загрузка расписания с LK-записью |

Иллюстрации, CSS, шапка, FAQ, контакты и community не заменяются.
Ссылка сообщества остаётся пустой: приглашение ВСК не выдано.

Выход требует **совместной** выкладки `subscription-storefront.js`,
`atlanty-schedule.js`, `group-schedule.js` (prod на 147, dev на 89),
соответствующих release manifests, серверного правила и затем T123.
Старый atlanty bundle игнорирует `bookingDisabledCategoryKeys`.
Нельзя публиковать T123 раньше проверки бандлов/правила/продажи продукта.

«Время на друзей» открывается через LK group-schedule с турнирным quote/action;
это исправляет прежний ошибочный маршрут GROUP_TRAINING. ВСК игры отображаются,
но запись для категорий `6975:1613` и `6975:2349` закрыта. Окно записи ограничено
`5278/839`: новый тариф/маршрут игр не имитируется. Для открытия ВСК игры нужны
подтверждённый тариф стоимости корта на четверых (решение владельца: платная часть со скидкой 30%), реальное будущее событие и проверка HTTP booking/quote,
включая доплату, daily/active cap, отмену и возврат. До этого весь запрос не завершён.
