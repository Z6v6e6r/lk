# Скидка на ПРО-тренировки по РА и Академии

Решение 2026-10-02: «РА» и «Академия», включая существующие промо-варианты этих продуктов,
дают скидку 50% на «Тренировку ПРО» и «Игра+Тренер ПРО» (направления 5502–5507;
новые направления определяются по отдельному токену «ПРО»).
При разовом тарифе 5 500 ₽ клиент платит 2 750 ₽. Посещение не списывается.
Первое бесплатное событие дня на ПРО не распространяется; оплаченная ПРО-тренировка
не расходует это право для следующего обычного занятия.

## Границы правила

- Право определяется точным ID продукта выбранной подписки, а не названием.
- Сохраняются проверки владельца, действующего периода, заморозки, даты покупки,
  исключённой станции, тарифа, лимитов, повторной проверки и привязки операции.
- Скидка разрешена только для действующей управляемой группы продаж и правила с 50%.
  Иной процент, историческая группа продаж или исключённая станция не дают право на ПРО.
- «Энергия 5/25» сохраняет существующую оплату посещением. Другие подписки на ПРО
  недоступны. Промокоды работают по прежнему отдельному сценарию.

## Источники и доставка

Изменены источники функций booking gateway (`gateway.js`, `gateway_hooks.js`) и
preview router (`router.js`), общая библиотека `proTrainingExclusion.mjs`, композиция
`patch_nodered_subscription_price_preview.mjs` и экран `GroupSchedulePage.tsx`.
Затронуты существующие API `/lk/subscription-bookings` и `/lk/subscriptions/game-price-preview`;
их входная форма не меняется. Внутренняя цель котировки получает серверный признак
`proTraining` для проверки цены и учёта первого бесплатного события.

Готовые flow JSON и import/export артефакты не хранятся в этом изменении.
`scripts/patch_live_lk1_pro_training_discount.mjs` воспроизводимо готовит кандидат
из закреплённого свежего live flow 147: меняются только `func` booking и preview,
остальные 4 802 узла, подключения и действующее ограничение «Топократии» сохраняются.
Скрипт отклоняет другой исходный hash и изменённые якоря. Кандидат и точный контракт
создаются с правами 0600 в новом каталоге 0700 под `/private/tmp`, вне Git.
Проверка фактической композиции запускается с `LK_PRO_TRAINING_DISCOUNT_LIVE_SNAPSHOT`
через `node --test scripts/tests/proTrainingDiscountRelease.test.mjs`.
Публикация требует проверенного контракта, guarded apply на 147 и frontend. Исторические hash-пины/квитанции не переписаны.
Один frontend без серверного изменения скидку не активирует.

Проверки покрывают точный расчёт, варианты РА/Академии, нулевой баланс посещений,
лимит активных записей, смешанные подписки, неподходящие правила, срок/заморозку,
имена новых ПРО-направлений и сохранение первого бесплатного обычного занятия.
