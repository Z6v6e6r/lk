# Версии и совместимость

## Текущая версия

| Ось | Значение |
| --- | --- |
| Схема подписи | `PADLHUB-PARTNER-GAME-V2` (первая строка канонической строки) |
| Контракт API | pilot v0.2 |
| Статус | контракт заморожен для пилота; боевой endpoint активирован, доступы партнёру не выданы |

Версия схемы подписи — единственная ось совместимости на проводе. Она входит в HMAC,
поэтому несовпадение версии ломает подпись, а не тихо меняет поведение.

## Политика совместимости

- **Обратимо-совместимые изменения** (новые необязательные поля в ответах, новые
  коды ошибок в уже существующих статусах) могут появляться без смены версии: клиент
  обязан игнорировать неизвестные поля ответа и ветвиться по известным кодам.
- **Несовместимые изменения** (изменение канонической строки, обязательных
  заголовков, семантики тела, статусов) выпускаются новой версией схемы подписи
  (`...-V3`) с параллельной поддержкой предыдущей на время миграции.
- **Запросы** остаются строгими: закрытая схема отклоняет неизвестные поля. Новые
  обязательные поля запроса — несовместимое изменение.
- Удаление кода ошибки или изменение его статуса — несовместимое изменение.

## Правила для клиента

- Не полагайтесь на порядок ключей в ответах и на отсутствие новых полей.
- Ветвитесь по `error.code`, а не по тексту `message`.
- Храните `keyId` в конфигурации, чтобы ротация не требовала релиза.
- Фиксируйте версию схемы подписи в конфигурации и уведомляйте о готовности к новой.

## История

| Дата | Версия | Изменение |
| --- | --- | --- |
| 2026-09-12 | pilot v0.2 / `...-V2` | Боевой endpoint активирован и проверен сквозным прогоном на тестовой игре: `POST` `201 ACTIVE`, `GET` `COMPLETED`, `DELETE` `200 REMOVED`, booking в Viva `ON_PLACE`. На проводе контракт не менялся |
| 2026-09-12 | pilot v0.2 / `...-V2` | Внутренняя правка сверки booking в Viva под фактический ответ провайдера (привязка упражнения по scope запроса, флаги отмены `isCancelled`/`cancellationDate`). Форма запросов, подпись и статусы для партнёра не изменились |
| 2026-09 | pilot v0.2 / `...-V2` | Три метода (`POST`/`DELETE`/`GET`), HMAC v2 с audience, nonce-ledger, idempotency, ownership, station/game allowlist, Viva на технического клиента |

Версии `v0.1` как публичного контракта не существовало. «v0.2» — внутренняя метка
пилота, а «V2» — токен схемы подписи; это разные вещи, не путайте их при поддержке.
