# Лендинг «ПадлхАБ × Бизнес-клуб» в Tilda: семь блоков T123

Исходный файл страницы весит **4,46 МБ**, и в один блок T123 он не влезает. Причина не в коде: самого кода там ~80 КБ, остальное — 26 встроенных base64 (6 шрифтов и вёрстка с картинками).

Что сделано:

1. **Ассеты вынесены из страницы** в файлы на `https://padlhub.su/lk/atlanty-page/` (13 файлов, 589 КБ). Тяжёлые картинки попутно сжаты: фоновая фотография 1,97 МБ PNG → **103 КБ WebP**, логотип «Алтанты» 335 КБ PNG → **24 КБ WebP**.
2. **Статичные карточки событий заменены на живую витрину расписания** (контейнер `#atlanty-schedule-root`), как и просили. Остальные секции не тронуты.
3. Страница **разрезана на 7 блоков** T123 — каждый можно вставить в Тильду отдельно (итого 88 КБ).

## Блоки и порядок вставки

| # | Файл | Что это | Размер |
| --- | --- | --- | --- |
| 1 | `1-settings.html` | Настройки витрины: категории, бейджи, лимиты | 3 КБ |
| 2 | `2-styles.html` | Стили страницы + `@font-face` (ассеты по ссылкам) | 40 КБ |
| 3 | `3-markup.html` | Разметка лендинга; в секции событий — контейнер витрины | 31 КБ |
| 4 | `4-page-scripts.html` | Скрипты страницы: тарифы, checkout подписки | 3 КБ |
| 5 | `5-schedule-loader.html` | Загрузчик витрины расписания | 3 КБ |
| 6 | `6-booking-popup.html` | Попап записи VivaCRM (инстанс `atlanty`) | 5 КБ |
| 7 | `7-theme.html` | Оформление витрины под палитру страницы | 3 КБ |

Ставить **в этом порядке**. Блоки 1, 5, 6 и 7 можно один раз положить в
«Настройки сайта → HTML-код внутрь BODY», а на странице держать только 2, 3 и 4 —
витрина сама дождётся настроек и стартует после `DOMContentLoaded`.

Если витрина на странице не нужна вовсе — не вставляйте блоки 1, 5, 6, 7, а в блоке 3
останется пустой `#atlanty-schedule-root` (это безвредно, но лучше убрать строку).

## Что изменилось относительно исходного файла

- Все `data:` заменены на ссылки `https://padlhub.su/lk/atlanty-page/...`; inline
  остались только два SVG-логотипа «ПадлхАБ» (9 КБ каждый) — так меньше запросов.
- Секция `#events`: вместо `<ul class="ph-events__track">` с восемью статичными
  карточками и кнопкой «next» стоит `<div id="atlanty-schedule-root"></div>`.
  CSS-правила `.ph-card` и обработчик `.ph-events__next` остались, но ничего не
  находят и просто не срабатывают.
- Картинки статичных карточек (те 8 фото) не выкладывались — они больше не нужны.
  Если понадобится вернуть статичную версию секции, они есть в исходном файле.
- Правило `html, body { margin: 0; padding: 0; }` из исходного файла сохранено.

## Как менять

- **Категории и бейджи расписания** — блок 1 (`ATLANTY_CATEGORIES`), пересборка бандла
  не нужна.
- **Оформление витрины** — блок 7 (CSS-переменные). Общие правила: правки в Tilda
  видны только на опубликованной странице, в редакторе код не исполняется.
- **Свои фото/шрифты** — положить файлы в `/var/www/html/lk/atlanty-page/` на `lk-primary-147`
  и заменить ссылки в блоках 2/3.

## Локальная проверка перед вставкой

Блоки — это фрагменты `<body>`, поэтому для проверки в браузере их нужно обернуть
в каркас документа:

```bash
cd docs/atlanty-landing-tilda
{ echo '<!doctype html><html lang="ru"><head><meta charset="utf-8">';
  echo '<meta name="viewport" content="width=device-width, initial-scale=1"><title>Проверка</title></head><body>';
  cat 1-settings.html 2-styles.html 7-theme.html 3-markup.html 4-page-scripts.html 5-schedule-loader.html 6-booking-popup.html;
  echo '</body></html>'; } > /tmp/atlanty-page-preview.html
open /tmp/atlanty-page-preview.html
```

В редакторе Tilda код не исполняется — витрину и попап видно только на
опубликованной странице.

## Проверки

- В собранных блоках не осталось ни одного `data:` кроме двух inline-SVG.
- Разметка блока 3 — цельный `<div class="ph-landing">…</div>`, теги сбалансированы
  (`div` 34/34, `section` 3/3, `ul` 3/3, `li` 12/12, `footer` 1/1, `button` 3/3).
- Все 13 ассетов отдаются с `https://padlhub.su/lk/atlanty-page/` со статусом 200 и
