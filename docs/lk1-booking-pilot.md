# Отдельный предпросмотр интерфейсов записи ЛК1

Вход пилота — `/lk-test`. Визуальный эталон — ЛК1 #339, `02000ad70bfc9ad3a832a00487de2d0b91d7fa2b`, `skin=lk2`. Данные, авторизация и расчёт из старого стенда с фикстурами здесь не используются. Страница читает действующую сессию Viva. Вход и обновление сессии выполняются в обычном ЛК на том же домене. Локальное хранилище пилота изолировано от состояния боевого ЛК. Дополнительного списка допуска и горячего переключателя у этого пилота нет.

| Окно | Что использует пилот |
| --- | --- |
| `game-booking` | Станции, слоты и разовая цена Viva. Применимость подписки через Node‑RED с целью `NEW_GAME`. |
| `game-list` | Список из Node‑RED и «Игра + тренер» из расписания Viva. |
| `game-join` | Карточка реальной игры из Node‑RED. Расчёт для `EXISTING_GAME`, если выбран вариант с участием по подписке. |
| `training-booking`, `training-join` | Расписание, карточка и разовый продукт Viva. Котировка для `GROUP_TRAINING`. |
| `tournament-booking`, `tournament-join` | Афиша, карточка и состояние участия ЦУП. Тариф Viva и котировка `TOURNAMENT`. |
| `matrix` | Сравнение недавних подтверждённых сумм из карточек в текущей вкладке. Для отсутствующей или просроченной цены нужно заново открыть событие. |

База и активный граф 147 совпали 25.11.2026. SHA-256 файла графа `6812c12a5d51fa51713a9b368353dd2ab5afe2110889c3fa9a8e0c82dd4d6da7`, 5 752 узла. Контракты просмотра и предварительного расчёта присутствуют. Это сверка графа и HTTP-доступности, а не приёмка конкретных сумм на авторизованной вкладке. В активном графе отсутствует ветка расчёта `GROUP_TRAINING_RESIDENCY_PURCHASE`. Нет подтверждённого единого расчёта для всех сочетаний прототипа `stage=full`, включая покупку РАбуста вместе с записью и модель лимитов ПРО. Пилот не показывает такие предложения с тестовыми ценами.

## Сборка и проверка

```sh
node --test scripts/lk-pilot/policy.test.mjs scripts/lk-pilot/routes.test.ts
node scripts/lk-pilot/build.mjs /absolute/new-output-dir http://127.0.0.1:24927/lk-test
node scripts/lk-pilot/server.mjs /absolute/new-output-dir 24927 http://127.0.0.1:24927
```

Локальный сервер не обращается к Viva, ЦУП и 147. Для сценариев с данными при локальной проверке передайте тестовую функцию `forward` в `createPilotServer`.

Новый артефакт `booking.js` и его манифест находятся под неизменяемым путём `/lk-pilot/<version>/`. Действующий Tilda-загрузчик ЛК1 не участвует в его выборе. Сборка для будущего размещения использует `https://padlhub.ru/lk-test` по умолчанию. Фрагмент `tilda-head.html` помещается в head **отдельной** страницы, фрагмент `tilda-block.html` — в её T123. Проверить CSP нужно по загруженной странице. В body браузер игнорирует CSP meta. Доступ к статике и `/lk-pilot-api` должен вести на этот прокси 147, который слушает только loopback. Размещение и публикация проверяются отдельно.

В пилоте закрыты команды записи, резерва, заказа, оплаты, отмены и автоматической сверки. Прокси пропускает узкие проверенные маршруты чтения и предварительный расчёт, использует существующий Bearer только для штатных upstream, не следует за редиректами. В вызове цены для действующего Резидентства установленный Node-RED вызывает CUP refresh. Этот путь сохраняет техническое наблюдение, при этом не создаёт бронь, платёж или списание посещения. Турнирное чтение с `refresh=if-stale` заблокировано, поскольку запускает обновление снимка. Боевые данные доступны только по обычным правилам upstream. Для запроса цены подписки прокси ждёт до 29 с, поэтому выделенному маршруту `/lk-pilot-api` нужен `proxy_read_timeout 30s` в Nginx. Остальные upstream-запросы прокси ограничивает 8 с. Действительные размещение, доступ по сессии Viva и другие сценарии боевого просмотра требуют отдельной приёмки.
